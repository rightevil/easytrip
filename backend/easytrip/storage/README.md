# 本机行程存储

P1 使用标准库 SQLite，不增加 ORM。`Database.initialize()` 在首次启动执行 `migrations/001_initial.sql`，以 `PRAGMA user_version` 记录版本；不兼容版本拒绝启动，不删除或重建用户数据。

存储行程、原始待处理消息和任务。行程条件与工作区采用 Pydantic 校验后的 JSON，目的地可空，默认交通为 `mixed` 并记录默认/用户来源。两类版本独立；更新与版本递增在同一事务中提交。写事务使用 `BEGIN IMMEDIATE`，启用外键、级联删除和 WAL。

新建与消息使用客户端操作 ID 幂等；同一 ID 不得用于不同内容。归档保留历史，恢复后可编辑；删除先使任务失效再级联清理。消息仅保存为待处理，不代表已经完成意图解析。

重开、并发版本竞争、回滚、幂等、归档/删除和未来版本保护由 `tests/test_storage.py` 验证。数据库文件保存在根目录被 Git 忽略的 `data/` 中，后续应用启动入口负责初始化。
