# 文档目录

本仓库提供 P0 验证程序、P1 草稿工作区和 P2 攻略发现实现。已审查的阶段记录：[P1 验收](p1-acceptance.md)、[P2 实施与验收](p2-acceptance.md)、[P2 人工审核](p2-review.md)。P2 真实语义验收仍未通过。后续仅将经过脱敏审查的设计文档纳入版本控制，并逐步归档到：

- `product/`：当前有效的产品需求和约束。
- `architecture/`：架构、接口及数据模型。
- `decisions/`：技术和产品决策记录。
- `research/`：调研及验证报告（不含账号信息和原始用户数据）。
- `archive/`：失效的历史方案。

为避免误传本地的 Cookies、API 凭证和其他未审查资料，当前 `.gitignore` 默认忽略 `docs/` 下所有新内容，仅跟踪已确认安全的文档入口。后续应逐一审查并显式加入需要版本化的文档。不要直接移除忽略规则后执行 `git add .`。
