- `product/`：当前有效的产品需求和约束。
- `architecture/`：架构、接口及数据模型。
- `decisions/`：技术和产品决策记录。

为避免误传本地的 Cookies、API 凭证和其他未审查资料，当前 `.gitignore` 默认忽略 `docs/` 下所有新内容，仅跟踪已确认安全的文档入口。后续应逐一审查并显式加入需要版本化的文档。不要直接移除忽略规则后执行 `git add .`。
