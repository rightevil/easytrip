本仓库提供 P0 验证程序、P1 草稿工作区、P2 攻略发现、P3 高德地点核对和候选地图，以及 P4 单日规划。阶段记录：[P1 验收](p1-acceptance.md)、[P2 实施与验收](p2-acceptance.md)、[P2 AI 初评与可选人工复核](p2-review.md)、[P3 实施与验收](p3-acceptance.md)。P2 工程及采用 AI 初评的评测交付已收尾，真实模型语义质量仍列为未通过项；人工复核不再是当前等待条件。P3 工程回归及真实 SDK 浏览器闭环已通过，20 个高德案例采用 AI 审阅，尚不构成人工消歧质量认证。后续仅将经过脱敏审查的设计文档纳入版本控制，并逐步归档到：

- `product/`：当前有效的产品需求和约束。
- `architecture/`：架构、接口及数据模型。
- `decisions/`：技术和产品决策记录。
- `research/`：调研及验证报告（不含账号信息和原始用户数据）。
- `archive/`：失效的历史方案。

为避免误传本地的 Cookies、API 凭证和其他未审查资料，当前 `.gitignore` 默认忽略 `docs/` 下所有新内容，仅跟踪已确认安全的文档入口。后续应逐一审查并显式加入需要版本化的文档。不要直接移除忽略规则后执行 `git add .`。
