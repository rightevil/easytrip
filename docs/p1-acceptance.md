## 使用与限制

在仓库根目录依次运行：

```powershell
./scripts/dev.ps1 setup
./scripts/dev.ps1 build
./scripts/dev.ps1 serve
```

访问 `http://127.0.0.1:8000`；独立 P0 地图为 `/p0/map`。再次启动只需 `serve`，代码更新后重新 `build`。脚本不安装全局工具、不修改系统代理、不启动或关闭小红书服务；`test` 为前后端自动回归。服务限一个后端进程和执行器，不支持多 worker。

已保存数据由 SQLite 恢复；尚未提交编辑与未发送消息只保留在当前会话，关闭前会提示，强制关闭仍可能丢失。磁盘无法写入时不会宣称已保存。硬中断阶段的耗时无法精确核算，`usage.interrupted_stage_time_unknown` 如实标注；已提交阶段的步骤与已知耗时保留。

没有执行整机断电试验；已验证真实后端进程停止 / 重启和数据库重开。测试依赖存在一条 Starlette 对 HTTPX TestClient 的弃用提示，当前回归通过，后续升级测试客户端时处理。

P1 本地准备任务的外部调用、模型 token 与图片数量均为零。小红书攻略理解、Agnes 意图解析、真实候选地图、正式方案快照及排程仍在 P2–P4；地图 / 时间表区域明确显示尚未接入。P0 剩余语义质量、服务浏览器出口和票价等真实性验收仍需在后续阶段补齐，P1 完成不替代这些验收。
