## 第一步验收：安全与确定性回归

修复三项可复现缺口：未知 `api_key/access_token/password/cookies` 等字段与复合值未完全脱敏；MCP 服务 schema 的外部引用可以绕开固定网络目标；第三方 SDK 警告/异常可能包含原始响应与凭证 URL。

统一参数校验拒绝外部 HTTP/file/相对引用，使用不检索资源的 Registry；本地 `$defs`、动态/递归锚点仍可校验，非法递归安全停止。XHS、采集和铁路使用同一入口，参数/服务 schema 错误不会启用写工具或追加外部下载。第三方 transport 日志只保留模块、级别与异常类，调用详情由受控台账记录。

新增实际应用回归覆盖恶意来源/schema 不能修改模型目标、预算或增加购票/写工具，陌生 Host/Origin 不能创建数据，模型鉴权失败的正文/凭证不进入任务 API；构造响应全部为脱敏测试数据，无真实调用。
