# 能力报告：P0 基线与 P6 有限实测

更新：2026-10-17。本文是经过脱敏审查的交付摘要，不包含平台原始内容、账号、带签名链接、私有配置或数据库；完整P6状态见 [验收报告](p6-acceptance.md)。

## P0 历史基线

2026-10-10/11 的有限样本验证了小红书只读采集、Agnes 文本/图片、官方高德 MCP、Web POI/路线与 JS 地图。用户确认当时浏览器地图验收通过。最新 P0 样本为5篇唯一笔记、42条一级评论、关闭二级回复；42条产生显式模型判断不等于42条语义均正确。该轮已知模型用量23895 tokens、实际提交3张图，原样本63张图并未全部理解。

POI及步行、公交、自行车、电动车真实响应有记录；P0 首项选择只是接口探测，正式分店确认在P3另行实现。小红书工具数18与官方高德工具数15只表示能力枚举，不代表业务效果。旧轮请求用量完整性未统一记录，不将成功轮小计当作历史总费用。

## 已知限制与未核定项

- 固定文本对象/主要维度已达标，性质62/75（82.7%）、立场55/75（73.3%）仍有误判；AI评审不构成人工认证或全平台准确率，图片/视频没有在本轮复测。每轮候选与评价仍需结合原文核对。
- 地点固定回归基于10-14官方快照与用户接受的AI审阅，不能认证当前营业、别名等价或全平台消歧准确率；推荐、推广/时效、预约、共享车辆、房价与车票保留原有限制。
- 人民币成本未核定。只记录已知tokens、图片、业务调用、缓存、失败与未知；当前账号单价、套餐、账单、地图底图/协议流量及用户服务资源没有完整核算。
- 没有承诺30篇负载稳定性、几秒完成、视频理解或所有真实权限/故障分支。确定性故障注入与真实小样本分别记录。

v11评测23次模型请求、493549已知tokens；加上v10诊断共27次、572450已知tokens、32768未知调用预留，另100000安全占额不是实耗或最终账单上限。本轮0图片/小红书/高德；这些评测用量与上表真实业务链路的5次模型请求分别核算。可复现入口及备份恢复见 [Windows说明](windows-operations.md)；最终版本与发布判定见 [交付说明](delivery.md)。
