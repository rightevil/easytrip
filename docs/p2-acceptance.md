第 4 步复用已有模型客户端和数据层。每篇笔记保存独立分析检查点；同一条件的后续轮次沿用不可变来源，并查找最近父轮的有效分析缓存。候选名称和文本引用须由原文支持，图片观察须指向实际提交的原图序号；无依据的可选分店线索清空，未关联的评论不产生地点体验票。候选只有文字和 `unmatched` 状态。来源发布时间只作为历史信息，不能证明当前营业、价格或政策。

补搜首次生成后固定计划，餐饮和住宿合计最多两次，并共用采集/模型/时间预算。中断后复用已完成的调用；未知或失败的模型请求不会在恢复时重新提交图片。每篇成功结果及时发布，后续失败保留已有候选，并显示停止原因、未知用量与未完成项。任务停止后的代际检查阻止迟到业务写入；实际调用费用台账独立结清。

Agnes 请求 `trust_env=False`，开启 `enable_thinking`；意图输出上限 16384 tokens，证据和唯一一次文本修复上限各 32768。图片最多每篇三张且不在修复中重送。记录实际 tokens、已提交图、原图覆盖和未知费用，不保存思考正文。提供者未确认人民币单价，不能从 token 数推导金额。
