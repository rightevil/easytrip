# EasyTrip 行程工作区

React + TypeScript + Vite，本地运行于 Node.js 24.15 或更高的 24.x。版本已锁定于 `package-lock.json`。

```powershell
cd E:\project\easytrip\frontend
npm ci
npm run dev
```

开发页面为 `http://127.0.0.1:5173`，后端需运行于 `http://127.0.0.1:8000`。Vite 仅绑定回环地址，代理 `/api`、`/p0` 和高德安全代理；仅将可信开发页面或无 Origin 的请求改写至本机后端，外部 Origin 保留供后端拒绝。前端不读取 `.env`，不接触服务密钥。

```powershell
npm test
npm run build
```

`dist/` 是生产构建产物，由同一个 FastAPI 后端托管。P0 地图保留在独立的 `/p0/map`。P2 提供有来源的文字候选；高德定位与正式地图仍属 P3，时间安排和方案生成仍属 P4，文字候选不包含假坐标。

行程条件与工作区分别按请求版本、工作区版本自动保存。保存失败保留编辑并显示重试，发生冲突时可加载最新版本或在最新版本上重新保存本地编辑；切换前尝试保存，失败时要求显式处理。本次会话中每个行程保有独立草稿，刷新或关闭前存在未保存修改会触发浏览器提示，关闭仍可能丢失未提交编辑。成功保存的数据由后端 SQLite 恢复。

新建行程、保存消息、启动任务和采用方向的重试使用同一操作 ID。“保存想法”仅保存原文；“保存并发现”先保存当前条件，再原子保存消息并创建发现任务。未知响应重试保留原操作 ID、条件版本和预算，服务未返回任务时明确提示未确认启动。切换行程不会让晚到的消息或任务响应落在另一份行程中。

“准备工作区”是本地任务：检查条件、读取已保存内容、汇总工作区。开始前先保存当前编辑；状态按行程与任务 ID 轮询，切换会停止旧页面轮询。取消需服务确认，重启中断的任务显示可恢复；恢复携带最新执行代次，旧条件的任务只保留历史。任务结果不覆盖行程条件、工作区或其它行程。P1 的本地任务不会调用外部服务。

“发现攻略”由后端调用小红书只读 MCP 和 Agnes。界面展示理解需求、发现、读取、抽取、评估与候选就绪的真实阶段，区分用户明确提供、程序默认、模型推测和未知值。每轮可调整目标笔记数、每篇一级评论上限与二级回复开关；默认目标 30 篇、每篇 20 条一级评论、二级回复关闭（开启时本轮总上限 20 条）。目标是预算上限，取得数量不作保证。

覆盖栏分别显示取得、选取、分析、判断及图片提交次数，图片分析覆盖按来源与原图序号去重，保留未分析数量。已知 token 与未结清预留分别显示；费用未结算时保持未知，token 不转换为人民币。登录受限、模型失败或响应不确定会保留已取得内容并说明原因。预算耗尽、阶段完成后的部分结果或模型重试有重复图片用量风险时，只能通过“继续一轮”确认新增预算，创建新任务；恢复沿用原预算与执行代次。行程累计调用量与每轮用量分别展示。

候选、原始来源快照、正负评价和吃住缺口均绑定任务和条件版本。没有评价证据的候选仍可查看支持名称提及的原文，这些来源不冒充赞成评价。证据区分体验、疑问、转述、愿望与对象歧义；图片观察标明原图序号并保持待核验，未提交图片与视频不声称已经理解。不可用图片保留原序号占位，仅合法 HTTP(S) 原图链接可供用户打开，不自动加载外部图片。采用探索方向需明确确认，会更新目的地及条件版本，旧版本候选只保留为历史。已有自动测试覆盖消息与任务晚到、版本保护、预算重试和来源隔离；构造数据的浏览器闭环检查及真实服务验证范围见 [P2 验收记录](../docs/p2-acceptance.md)。当前工程与 AI 初评交付已收尾，逐条人工审核按用户决定跳过；界面继续提示模型语义质量未验证，候选与评价需结合原文核对。
